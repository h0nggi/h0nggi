> AI 기반 가구 추천 및 3D 공간 배치 서비스

**Project Status:** In Progress

#### Project Overview

사용자가 자신의 주거 공간에 적합한 가구를 선택하고,
구매 전 가구 배치와 반입 가능 여부를 확인할 수 있도록 지원하는 서비스입니다.

#### Key Features

- 이미지 분석을 통한 가구 종류 식별
- 가구 정보 및 사용자 입력 치수 기반 상품 추천
- 3D 가상 공간 내 가구 배치 및 회전
- 가구 배치 시 공간 경계 및 겹침 확인
- 문과 복도의 치수를 활용한 가구 반입 가능 여부 점검

#### My Responsibilities

- 서버 인프라 및 서비스 배포 담당
- AWS 기반 클라우드 배포 환경 설계
- 서비스 운영 환경 및 안정성 검토
- 팀원 간 개발 및 서비스 통합 협업

#### Results

- 가구 추천 및 3D 공간 배치 시제품 구현
- 가구 치수 기반 반입 가능 여부 점검 기능 구현
- Chrome 및 macOS Safari 환경에서 주요 기능 검증
- AWS 기반 서비스 배포 준비 진행 중

#### Lessons Learned

- 애플리케이션 개발과 인프라 운영 간의 연관성 이해

- 팀 프로젝트를 통한 역할 분담과 기술적 의사소통 경험
